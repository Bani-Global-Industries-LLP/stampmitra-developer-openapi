# Security Policy

Please report vulnerabilities privately to **security@stampmitra.in** (see https://developer.stampmitra.in/.well-known/security.txt). Do not open public issues for security problems.

Include a description, reproduction steps and impact. We aim to acknowledge reports within 3 business days.

This repository contains only the public API contract and test assets. It must never contain real API keys, webhook secrets or personal data; fixtures use placeholder values (`sk_test_EXAMPLEKEY...`, `whsec_test_...`). If you find a real credential here, report it immediately via the address above.
