# Contributing

This repo mirrors the StampMitra Developer API contract. **The portal (https://developer.stampmitra.in) is the source of the contract**; do not hand-edit `openapi.json` or `postman.json` except to fix the sync tooling. Contract changes arrive through the daily `sync.yml` PR (or `npm run sync`).

## Setup
```bash
npm ci
npm test            # validate spec + check fixtures/vectors + mock server smoke test
```

## What you can change
- `scripts/` - tooling. `scripts/build-fixtures.mjs` is the source for `fixtures/operations/*` (edit the generator, then `npm run build:fixtures`; never hand-edit generated files).
- `fixtures/validators.json`, `fixtures/retry-scenarios.json` - hand-maintained vectors. Validator patterns must match the backend DTOs.
- `fixtures/webhook-signatures.json` - generated by `npm run build:webhook-vectors`.
- `CHANGELOG.md` - required for every contract change.

## Pull requests
Keep them focused; make sure `npm test` passes; follow the PR template. Never commit secrets or real personal data (PAN, GSTIN, account numbers) - use the existing placeholder values.
